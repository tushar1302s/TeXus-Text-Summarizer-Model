# 🤖 GenAI Text Summarization

A simple Generative AI project for automatic text summarization using
Hugging Face Transformers and the DistilBART model.

## 🚀 Features

- Text summarization using DistilBART
- Hugging Face Transformers
- PyTorch
- NVIDIA CUDA GPU acceleration
- Local model inference
- Python virtual environment
- Easy setup using requirements.txt

## 🛠️ Technologies Used

- Python
- PyTorch
- Hugging Face Transformers
- DistilBART
- CUDA
- Gradio
